# 识别算法

## 人脸

- v1 采用 YuNet DNN（`cv2.FaceDetectorYN_create` + onnx 约 230KB）：正/侧脸均可、精度远高于 Haar；模型经 `fetch_model.py --yes` 用户确认后拉取到固定缓存，不随包分发。
- 重要教训：OpenCV 5.0 主命名空间已移除 Haar `CascadeClassifier`（`cv2.data.haarcascades` 目录属性仍在但类没了）——4.x 教程的人脸代码在 5.x 直接 AttributeError，选型时必须实测。
- 备选：mediapipe（依赖重、带 landmark 关键点），未接入，列为扩展点。

## 二维码 / 条码

- `cv2.QRCodeDetector.detectAndDecode` 单码为主；低分辨率/斜角弱。
- WeChatQRCode（opencv-contrib 的 objdetect 模块）成功率显著更高，但需 contrib 包与模型文件，列为扩展。
- 条码（一维）：zxing-cpp python 包可选，未接入。

## 运动 / 变化检测

- 帧差法：灰度→高斯模糊(21×21)→`absdiff`→阈值 25→非零占比；占比>0.05 判「有变化」。
- 阈值 0.05 兼顾光照抖动与漏报；纯光照变化可用直方图均衡预处理再比。
- 光流（Farneback/calcOpticalFlowPyrLK）能给出方向矢量场，输出契约不匹配，未接入 v1。
