# 隐私与合规

## 底线

- 摄像头是隐私敏感设备：**未经当事人知情不得持续拍摄他人**；对他人使用本 skill 前先取得明确同意。
- 每次调用摄像头（含枚举）写一条 `NOTICE.md`（时间/操作/文件名），用户可随时查看删除——这是"每笔告知"的本地实现。
- `frames` 连拍必须显式 `--n>=2`，即要求用户主动声明批量意图；脚本不做默认连拍。

## 数据边界

- 帧图像只写固定缓存 `camera_vision/captures/`（平台缓存目录下），不写 skill 目录、不写用户工程目录。
- 不上传：全链路本地（OpenCV 推理 + 本地 OCR），无 network 调用。
- 留存：默认建议 7 天，`camera.py clean --keep-days` 手动清理；skill 不起常驻后台进程。
- OCR 命中的证件号/银行卡等敏感串：agent 回复时只报类别与行数，不复述原文。

## 与 SMS 隐私体系的关系

- SMS（skill_manage_system）的 `privacy.py` 管 SMS 自身背景采集授权；本 skill 独立运行，两者互不写对方目录。
- 若 SMS 会话调度本 skill，SMS 侧按其 permissions 门控记录；本 skill 侧照常写自身 NOTICE。
